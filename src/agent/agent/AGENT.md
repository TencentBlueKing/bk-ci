# Agent 开发约定

本文件记录当前 Agent 模块的开发规范，适用于本目录及其子目录。

## 中文注释规范

- 后续新增或修改代码时，使用中文编写注释，并提供足够详细的说明。
- 新增函数、状态结构和关键分支应说明职责、设计原因、调用前提及边界情况；避免仅将代码逐行翻译成自然语言。
- 涉及状态或计数时，说明字段含义、统计范围、更新和重置时机，以及状态变化之间的关系。
- 涉及并发时，说明状态由哪个协程持有、是否需要加锁、锁保护的范围，以及与其他缓存或全局变量的关系。
- 涉及异常、限频、去重或回退时，说明哪些情况立即处理、哪些情况被抑制，以及如何保留错误信息和恢复信号。
- 测试注释说明被验证的行为、关键边界和回归风险；时间边界优先使用传入时间验证，避免真实等待。
- 修改现有代码时，将本次涉及的新增英文注释改为中文。标识符、协议字段和已有日志文本继续遵循项目现有约定。
